# pigsec releases

Public Linux and macOS binaries for pigsec. Source code is maintained in a separate private repository.

Download the matching binary from [Releases](https://github.com/pig-dev-team/pigsec-releases/releases), make it executable, and run it in a terminal.

The program checks this repository for updates at startup. Pass `--no-update-check` to disable updates. `--skip-network` also disables update checks.
